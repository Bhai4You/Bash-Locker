#  Installation Steps...

<pre>
1) apt update && apt upgrade -y
2) apt install git
3) git clone https://github.com/Bhai4You/Bash-Locker.git
4) cd Bash-Locker
5) chmod +x requirement.sh Bash-Locker.sh
6) bash requirement.sh
7) bash Bash-Locker.sh
</pre>
